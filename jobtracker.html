Set Up in 6 Easy Steps

No coding knowledge needed — just copy, paste, and go

1
Create a Google Sheet
Go to sheets.google.com and create a new blank spreadsheet. This will be your tracker's home.
2
Open Apps Script
Inside the sheet, go to Extensions → Apps Script. This opens the script editor where the magic happens.
3
Paste the Script
Delete the existing code in the editor, then paste the full JobTracker script. Hit Ctrl + S to save.
4
Install Triggers
Run these two functions once to activate automation:
installTrigger() 📋
installDailySummaryTrigger() 📋
⏱️ Auto-scan every 15 min • 📧 Daily summary at 8 AM
5
Authorise Permissions
Google will ask for Gmail + Sheets access. Click Allow to proceed.
🔒 Everything stays in your own Google account — nothing is shared externally.
6
Run First Scan
Select runTracker from the function dropdown, click ▶ Run, and you're done!
runTracker() 📋

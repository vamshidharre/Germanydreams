6 Simple Setup Steps

No programming skills required — copy, paste, and run.

1
Create a Spreadsheet
Open sheets.google.com and create a blank new spreadsheet.
2
Open Apps Script
In your sheet menu, click Extensions → Apps Script to open the automation editor.
3
Paste the Code
Clear the default code in the editor, paste the JobTracker script, and press Ctrl + S to save.
4
Install Triggers
Run these functions once in the dropdown to set up background timers:
installTrigger() 📋
installDailySummaryTrigger() 📋
5
Authorize Access
Click Allow when Google requests permission to read Gmail and write to your Google Sheet.
6
Execute First Scan
Select runTracker from the function list and click &blackright; Run.
runTracker() 📋
